# 验收清单

## 信息架构

- [ ] 默认进入演示页或首页明确引导到演示页；
- [ ] 顶部导航包含首页、演示、开发者、诊断、关于；
- [ ] 设备选择只出现一次，位于演示页顶部；
- [ ] 没有独立设备管理和权限管理 Tab；
- [ ] Touchpad 只作为独立插件说明，不复制业务。

## 链接演示

- [ ] GitHub 快捷入口填入正确项目地址；
- [ ] Synra 文档快捷入口填入 `https://synra-app.dev`；
- [ ] 输入合法链接可以发送并打开；
- [ ] 无效链接在本地被拒绝；
- [ ] 目标离线、能力拒绝、超时和失败状态可区分；
- [ ] 成功状态只有在电脑端确认实际打开后显示。

## 剪贴板演示

- [ ] 电脑选中文本可以返回手机；
- [ ] 返回内容写入手机剪贴板；
- [ ] 手机剪贴板内容可以发送到电脑；
- [ ] 超长内容被拒绝并说明限制；
- [ ] 调用记录不泄露完整剪贴板文本；
- [ ] 浏览器预览不伪造原生剪贴板成功。

## 应用坞演示

- [ ] 目标电脑可返回安全白名单应用；
- [ ] 应用显示名称和图标；
- [ ] 应用项使用稳定 ID，不暴露任意执行路径；
- [ ] 点击应用可以请求电脑打开；
- [ ] 列表为空、离线和打开失败均有明确状态。

## 视觉与响应式

- [ ] 参考主程序主题 token，颜色和控件密度统一；
- [ ] 390px、768px、1024px、1280px 宽度下无横向溢出；
- [ ] 粗指针环境下按钮和应用图标有足够触控面积；
- [ ] 深色模式可读；
- [ ] 键盘焦点可见；
- [ ] 加载和错误文本不会造成主要布局跳动。

## 工程验证

- [ ] `cargo fmt --all --check`；
- [ ] `cargo clippy --locked --all-targets -- -D warnings`；
- [ ] `cargo test --locked`；
- [ ] UI 类型检查和测试；
- [ ] 构建真实 Wasm component；
- [ ] 执行 `synra-plugin verify`；
- [ ] 真实 Windows 宿主验证 URL、剪贴板和应用打开；
- [ ] 明确区分模拟测试与实体设备验收。
