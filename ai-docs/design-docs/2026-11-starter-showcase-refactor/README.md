# Starter Showcase 重构

本目录记录 `@synra-plugin/starter` 的 UI 与演示能力重构方案。

## 目标

把 Starter 从单一调试页重构为 **Synra 能力展示页 + 插件开发参考页 + 诊断工具**：

- 首屏让用户快速理解 Synra 的设备协作和插件模型；
- 用三个极简真实演示展示插件价值；
- 让设备选择、状态、权限和错误反馈服务于演示，而不是变成独立管理面板；
- 视觉和交互遵循主程序 UI 重构的密度、层级、触控和状态表达原则；
- 不把 Touchpad 业务复制到 Starter，Touchpad 继续由独立插件承担。

## 当前范围

演示页包含三张卡片：

1. **让电脑打开链接**：发送链接到选定电脑并自动打开，提供 GitHub 和 Synra 文档快捷入口；
2. **剪贴板**：电脑选中文本复制到手机，以及手机剪贴板内容发送到电脑；
3. **应用坞**：读取电脑允许展示的应用名称和图标，点击后请求电脑打开对应应用。

电脑确认步骤不属于 Starter 演示流程；本方案只讨论 Starter 专用演示入口，不修改其他插件或 Synra 核心的全局确认策略。
