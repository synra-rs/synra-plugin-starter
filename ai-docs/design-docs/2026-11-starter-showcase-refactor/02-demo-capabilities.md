# 演示能力

## 1. 让电脑打开链接

卡片结构：

```text
让电脑打开链接

[请输入链接                         ] [发送并打开]
[GitHub] [Synra 文档]
```

### 行为

- 输入框允许输入链接；
- GitHub 和 Synra 文档按钮填入预置地址，推荐先填入再发送；
- 发送后由 Starter 的演示 action 请求目标电脑打开链接；
- 页面显示发送中、成功、目标离线、能力不可用、超时和失败状态；
- 只允许发送宿主平台明确支持的 URL，不能让插件自行执行任意命令。

预置地址：

- 项目 GitHub：`https://github.com/synra-rs/synra-plugin-starter`；
- Synra 文档：`https://synra-app.dev`。

## 2. 剪贴板

### 电脑到手机

```text
点击复制电脑选中的文本，点击按钮后，这里文本变成电脑选中的，并且手机要复制到剪贴板

[复制电脑选中]
```

成功后：

- 结果区域显示电脑返回的文本；
- 页面调用浏览器/宿主剪贴板能力写入手机剪贴板；
- 显示“已复制到手机剪贴板”；
- 不把完整文本写入调用记录。

### 手机到电脑

```text
点击发送手机复制内容，点击按钮后，变成已发送的内容

[发送复制内容]
```

成功后：

- 读取手机当前剪贴板；
- 发送到目标电脑；
- 显示已发送内容的安全摘要或截断预览；
- 超长、无权限、剪贴板不可用和目标离线均提供明确反馈。

## 3. 应用坞

```text
应用坞

[应用] [应用] [应用] [应用] [应用] [应用]
[应用] [应用] [应用] [应用] [应用] [应用]
```

### 行为

- 演示页加载或目标电脑变化时，按需读取电脑允许展示的应用列表；
- 应用项包含稳定应用 ID、显示名称和图标；
- 点击应用后仅发送稳定应用 ID，请求电脑打开已登记的应用；
- 不接受手机传入任意可执行路径；
- 显示加载、空列表、离线、打开中、成功和失败状态。

### 范围控制

应用列表属于演示用的安全白名单，不等同于读取电脑全部安装软件。桌面端负责决定可展示应用、图标来源和打开方式。

## 4. 目标电脑

演示页顶部共享一个目标选择器：

```text
目标电脑：[我的电脑 · 在线 ▼] [刷新]
```

- 不自动选择第一台电脑；
- 离线设备可以显示，但动作按钮应禁用并解释原因；
- 配对状态、在线状态、插件授权和具体动作能力分开表达；
- Starter 演示不显示电脑确认步骤，使用已选择且已授权的目标直接执行；
- 该免确认策略只属于 Starter 演示入口，不改变其他插件的全局安全策略。
